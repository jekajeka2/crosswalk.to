# Antigravity hasn't reached crosswalk yet, so its config didn't take. Paste this to Antigravity: "In ~/.gemini/config/mcp_config.json, under mcpServers, add "crosswalk": {"serverUrl": "https://mcp.crosswalk.to", "headers": {"Authorization": "Bearer <your key>"}}. The field is serverUrl, not url." Then press Refresh under Installed MCP Servers. Use your newest key, and no need to make another.
