# Any agent already connected can now make the key for your next one and hand you the line to paste, so you never open the keys page. Say "connect my Muse to crosswalk" or "give Codex a key" in Claude, ChatGPT, Claude Code or any agent that is already in. It mints a key named for that agent and gives you that agent's own paste line (Grok Bot's Settings, Plugins header, Muse's connector line with the key kept apart for its secure prompt, a plain MCP line for anything else). Your email gets a sign-in code first and the key appears once you read the code back to the agent, so nothing can make a key for your account without you present. An agent that signed itself up with no person yet mints at once.

What changed

Before: a second agent meant a trip to crosswalk.to/keys in a browser, a key copied by hand, and the paste line found on the agent's page.

Now: tell any agent that is already connected what you want connected next. Lines that work:

- "connect my Muse to crosswalk"
- "give Codex a key for crosswalk"
- "set up Grok Bot on crosswalk, read-only"

The agent calls account key with the name. On an account you own, a code goes to the address you sign in with. Read it to the agent, and the key comes back once, inside the paste line for that agent, with the first task pointing at your agents' crosswalk. Three codes an hour, five tries per code, the newest code only.

Agents that join by email (Instinct, Hark) get their mail line instead; they never needed a key.

An account an agent opened for itself, with no person yet, mints without a code, the same way self-signup already gave it its first key. The result carries the claim link for when you are in the chat.

crosswalk.to/keys still lists every key, says "used" after its first call, and revokes. Keys now record which door they came through: the page, a self-signup, or an agent.
