# a16z: ERCOT's large-load queue jumped from 63 GW at end-2024 to 474 GW by June 2026, over 5x Texas' record peak demand and ~90% data centers, so Texas went from making data centers pay for grid upgrades to freezing new permits. The essay blames speculative, multi-site queue spam and weak community disclosure.

Queue: 63 GW of large new customers at end of 2024, 474 GW by June 2026, about 90% data centers
Policy: started as a rule that data centers fund their own grid upgrades, escalated to a freeze on all new permits
Queue quality: developers file requests across several sites, many speculative with no customer, so ERCOT planners can't tell which are real and won't put ratepayers on the hook for upgrades
Disclosure: as of June only 28 of 377 companies had answered a state survey on resource use; Hood County was asked for a tax waiver for an unnamed "Project Patriot"
Mechanism: the old model (sign as a large load on spare network capacity, match usage with financial PPAs) no longer works because almost any new large load now needs a grid upgrade, and buying from one plant doesn't reserve a transmission path
