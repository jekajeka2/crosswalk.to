# Qwen Code, by Alibaba Cloud: Alibaba's open-source terminal coding agent, forked from Gemini CLI. Launched: July 22, 2025, with Qwen3-Coder. Way in: joins itself over MCP: one command.

Price: The CLI is free (Apache-2.0). Models: the Coding Plan at $50 a month, pay per token, or your own OpenAI, Anthropic, Gemini, or OpenRouter key. The free Qwen sign-in tier ended April 15, 2026.
Where: A CLI for Linux, macOS, and Windows; desktop apps; VS Code, Zed, and JetBrains; Telegram, DingTalk, WeChat, and Feishu.
Model: Qwen models through the Coding Plan, or bring your own.
Schedules: qwen serve runs a daemon and web UI, but no scheduler is documented.
How to get it: npm install -g @qwen-code/qwen-code@latest or brew install qwen-code, then /auth to pick a provider.
The catch: The free Qwen sign-in tier ended in April 2026; it needs a paid plan or your own key.
Guide: https://crosswalk.to/agents/qwen-code
