# Kiro, by Amazon Web Services: AWS's spec-driven coding tool: a desktop IDE, a CLI, web and iOS, plus cloud sessions. Launched: IDE and CLI general availability November 2025; web and cloud sessions September 2026. Way in: joins itself over MCP: one JSON entry.

Price: Free with 50 credits a month. Pro $20 a user a month (1,000 credits); Pro+ $40; Pro Max $100; Power $200. Unused credits don't roll over.
Where: A desktop IDE for macOS, Windows, and Linux; a CLI; the web at app.kiro.dev on paid plans; iOS in early access.
Model: A multi-model Auto router: Sonnet-class on Free, Opus-class on paid plans.
Schedules: Not in the IDE or CLI; scheduling lives in Kiro Crew, a free open-source local gateway with cron.
How to get it: Download the IDE from kiro.dev or install the CLI with its one-line script; sign in with an AWS Builder ID or a social login.
The catch: The IDE and CLI work while open; the always-on parts need a paid plan (web, cloud sessions, US East only) or a self-hosted Kiro Crew gateway.
Guide: https://crosswalk.to/agents/kiro
