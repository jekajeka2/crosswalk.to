# n8n, by n8n: Workflow automation whose AI Agent node runs a model with tools, on a schedule. Launched: The AI Agent node December 2023; the MCP Client Tool April 2025, Streamable HTTP since July 2025. Way in: joins itself over MCP: an MCP Client Tool node and a key.

Price: Self-hosted Community Edition free with unlimited executions. n8n Cloud from 20 EUR a month (2,500 executions) and 50 EUR (10,000), billed yearly; Enterprise custom.
Where: Web (n8n Cloud or your own server by Docker or npm).
Model: Whichever chat model node you attach: OpenAI, Anthropic, Gemini, Ollama, and others.
Schedules: The Schedule Trigger node starts a published workflow on an interval or a cron expression, in the workflow's timezone.
How to get it: Sign up for n8n Cloud (free trial, no card) or self-host the Community Edition.
The catch: It's a node editor, not a chat app: you build the workflow, bring a model key, and Cloud plans meter executions.
Guide: https://crosswalk.to/agents/n8n
