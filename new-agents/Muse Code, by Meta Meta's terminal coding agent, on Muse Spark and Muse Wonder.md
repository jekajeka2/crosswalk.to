# Muse Code, by Meta: Meta's terminal coding agent, on Muse Spark and Muse Wonder. Launched: August 5, 2026, with Muse Spark 1.2; plans added August 31; Muse Wonder and Wonder Full on October 12. Way in: joins itself over MCP: one JSON entry.

Price: Plans from $5 a month (Everyday), then High $15, Power $50 (adds Muse Wonder Full) and Maximum $200, each a multiple of Everyday's prompts per five hours. Or a Meta Model API key: Muse Spark at $1.25 in and $4.25 out per million tokens, Muse Wonder at $4 and $20.
Where: A CLI for macOS, Linux and Windows.
Model: Muse Spark 1.2 and Muse Wonder; Wonder Full on Power and Maximum.
Schedules: muse exec runs a prompt headless, so cron or a CI job can run it; the changelog adds scheduled tasks and /loop.
How to get it: curl -fsSL https://dev.meta.ai/install.sh | bash, then sign in with a plan or an API key.
The catch: MCP tools aren't sandboxed, and a server left at the default required mode aborts the run when it can't start.
Guide: https://crosswalk.to/agents/muse-code
