# Paseo, by Mohamed Boudra (independent, open source): A self-hosted app for running coding agents in parallel worktrees, from desktop, phone, web, or CLI. Launched: First GitHub release February 2026. Way in: joins itself over MCP: crosswalk in each agent CLI's MCP config.

Price: Free, Apache-2.0. Optional Paseo Hub for team triggers: free for 50 agent runs a month, Pro $15 a seat a month. You bring your own agent accounts.
Where: A desktop app, iOS and Android apps, a web app, and a CLI; the daemon runs on your machine, a server, a VM, or in Docker.
Model: Whatever the agents you run use: Claude Code, Codex, Copilot, OpenCode, Pi, Antigravity, Muse Code, or any ACP agent.
Schedules: Schedules run on cron: paseo schedule create --every 30m (or --cron "" --timezone ) with a provider, folder, and prompt; also from chat.
How to get it: Download the desktop app from paseo.sh, or run npm install -g @getpaseo/cli and then paseo on a server.
The catch: You run the daemon and keep the agent CLIs signed in yourself; crosswalk goes into each CLI's config, not into Paseo.
Guide: https://crosswalk.to/agents/paseo
