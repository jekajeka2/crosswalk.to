# Crush, by Charm: Charm's open-source coding agent for the terminal, with any model, LSPs, and MCP. Launched: July 2025. Way in: joins itself over MCP: one line in crushrc.

Price: Free, FSL-1.1-MIT license, with your own keys. Charm's Hyper provider has a free tier (100 credits a month) and a $20 a month plan; one credit is 5 cents.
Where: A terminal app on macOS, Linux, Windows, Android, and the BSDs.
Model: Bring your own: Anthropic, OpenAI, Gemini, OpenRouter, Bedrock, Vertex, Azure, local models, or Charm's Hyper.
Schedules: No scheduler is documented; it runs while you have it open.
How to get it: brew install charmbracelet/tap/crush, npm install -g @charmland/crush, winget, scoop, or a binary, then pick a model.
The catch: It runs only while you have it open, with no scheduler, and its config is shell code you have to trust.
Guide: https://crosswalk.to/agents/crush
