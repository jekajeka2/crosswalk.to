# CLI Manager, by Solhun Jeong: An open-source macOS app that runs Claude Code, Codex CLI, and Gemini CLI sessions side by side, with worktree workspaces and a local API that lets one agent drive the others. Launched: November 2025; Product Hunt #10 Product of the Day in December 2025. Open source since v1.5.0. Way in: joins itself over MCP: crosswalk in each agent CLI's MCP config.

Price: Free, MIT license. You pay for the agent CLIs you run.
Where: A desktop app for macOS (Apple Silicon and Intel). Windows is planned.
Model: Whatever the CLIs you run use: your own Claude Code, Codex, or Gemini CLI login.
Schedules: No scheduler; a Loop Dashboard tracks Claude Code /loop sessions per project.
How to get it: Download the .dmg from the GitHub releases, then sign in to the agent CLIs you already use.
The catch: macOS only, and sessions run only while the app is open; the AI Control API is off by default and listens on localhost only.
Guide: https://crosswalk.to/agents/cli-manager
