# Superset, by Superset Inc.: A desktop app for running many CLI coding agents at once, each in its own git worktree. Not Apache Superset. Launched: First desktop release December 2025. Way in: joins itself over MCP: crosswalk in each agent CLI's MCP config.

Price: Free for one user (local workspaces, desktop app, CLI). Pro $20 a user a month, or $15 billed yearly, adds automations, remote access, mobile, Linear and Slack. Enterprise is custom.
Where: A macOS desktop app (experimental Linux AppImage), a CLI, a TypeScript SDK, and an iPhone and iPad app.
Model: Whatever the agents you run use: Claude Code, Codex, OpenCode, Gemini, Cursor Agent, and other CLI agents.
Schedules: Automations (Pro): run an agent session on a project on a schedule (hourly, daily, weekdays, weekly, or a custom rule); each run fires on the device you picked and leaves a workspace to review.
How to get it: Download it from superset.sh; it needs git and a signed-in GitHub CLI, plus the agent CLIs you use.
The catch: Automations, remote access, and mobile need Pro; source-available under the Elastic License, not open source; macOS first.
Guide: https://crosswalk.to/agents/superset
