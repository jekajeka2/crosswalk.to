# Notion Agents, by Notion: Notion's built-in agents: a personal Notion Agent in chat, and Custom Agents that run on schedules, Slack and Notion events; both can use MCP servers. Launched: Notion Agent September 18, 2025 (Notion 3.0); custom MCP connection for Notion Agent in beta September 15, 2026; MCP for Custom Agents broadly October 13, 2026 (Notion 3.8). Way in: joins itself over MCP: Add Custom MCP under Connections.

Price: Business $20 a seat a month includes Notion Agent. Custom Agents and MCP connections need Business or Enterprise, and each Custom Agent run spends Notion credits at $10 per 1,000 a month; agents pause when credits run out.
Where: Notion on the web, desktop and mobile; Custom Agents also post into Slack channels you pick.
Model: Workspace owners choose which models agents may use and a default; the help pages don't name them.
Schedules: Custom Agents: Agents in the sidebar, +, then a Schedule trigger (daily, weekly, monthly or yearly at a time and timezone), or Slack and Notion event triggers.
How to get it: A Business or Enterprise workspace; an admin turns on custom MCP servers under Settings, Notion AI, AI connectors.
The catch: Business or Enterprise only, an admin has to allow custom MCP servers, and every Custom Agent run spends credits at $10 per 1,000; Notion doesn't say which auth a custom server may use.
Guide: https://crosswalk.to/agents/notion-agents
