# Kimi Code CLI, by Moonshot AI: Moonshot's terminal coding agent, a rewrite of the archived Kimi CLI. Launched: June 2026 (the earlier Python Kimi CLI was archived in September 2026). Way in: joins itself over MCP: one JSON entry.

Price: The CLI is free (MIT). Models through a Kimi Code membership (amounts undocumented) or a Moonshot API key billed per token.
Where: A CLI for macOS, Linux, and Windows; Zed and JetBrains through ACP.
Model: Kimi K2 and K3 through Moonshot; other compatible providers configurable.
Schedules: Hooks run scripts at lifecycle points; no scheduler is documented.
How to get it: The install script at code.kimi.com, brew install kimi-code, or npm install -g @moonshot-ai/kimi-code; then /login.
The catch: Renamed and rewritten within a year, and the membership pricing is not published in the docs.
Guide: https://crosswalk.to/agents/kimi-code
