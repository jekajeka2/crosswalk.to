# OpenClaw, by OpenClaw Foundation: A self-hosted, open-source personal agent that meets you in your chat apps. Launched: January 30, 2026 under this name (Clawdbot and Moltbot before it). Way in: joins itself over MCP: an MCP server in its settings and a sign-in.

Price: Free, MIT license, no paid tier. You pay your model provider.
Where: Your own machine or server (macOS, Linux, WSL2, Windows), a CLI, a web control UI, iOS and Android nodes; 33 chat channels including Telegram, WhatsApp, Discord, Signal, Slack, iMessage, and Teams.
Model: Bring your own: Claude, OpenAI, DeepSeek, or a local model.
Schedules: openclaw automations create (alias openclaw cron): one-shot, interval, or cron expressions; the gateway wakes the agent and delivers to a chat channel.
How to get it: Run the install script from openclaw.ai, then openclaw gateway install; needs Node 24 and a provider API key.
The catch: You host and secure it yourself, and it has no built-in way to send email (community skills only).
Guide: https://crosswalk.to/agents/openclaw
