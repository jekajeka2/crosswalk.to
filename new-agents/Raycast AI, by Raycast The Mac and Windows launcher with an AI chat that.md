# Raycast AI, by Raycast: The Mac and Windows launcher with an AI chat that reaches MCP servers and runs prompts on a schedule. Launched: Raycast AI beta February 22, 2023; MCP servers in v1.98 on May 8, 2025; Windows 2.0 out of beta August 21, 2026. Way in: joins itself over MCP: the Install MCP Server command.

Price: Free (50 AI messages). Pro $10 a month or $96 a year (500 credits); Pro + Advanced AI $20 or $192 a year (3,000 credits); Max $50 (7,500 credits). Teams Pro $15 a user a month. MCP servers and Automations are Pro features.
Where: macOS, Windows, and iOS (HTTP MCP servers only on iOS).
Model: Fast models on Pro, top-tier models on Advanced AI and Max; each model spends credits at its own rate.
Schedules: Automations (Pro): Settings, AI, Automations, Create Automation; Once, Hourly (every 1 to 24 hours), Daily, or a custom cron. Each run is an AI Chat message that can use your MCP servers. The device must be awake with Raycast open.
How to get it: Download from raycast.com, sign in, start the Pro trial or subscribe.
The catch: Automations run only while the Mac or PC is awake with Raycast open and stay on that one device; MCP and Automations need Pro.
