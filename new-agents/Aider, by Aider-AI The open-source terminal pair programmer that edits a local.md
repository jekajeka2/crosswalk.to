# Aider, by Aider-AI: The open-source terminal pair programmer that edits a local git repo with any model. Launch date: not documented by the maker. Way in: no way in yet: no MCP support.

Price: Free, open source (Apache-2.0); you pay your model provider.
Where: A CLI, with an optional browser UI; Docker, Codespaces, Replit.
Model: Bring your own.
Schedules: No scheduler; a scripting page covers driving it from scripts.
How to get it: python -m pip install aider-install, then aider-install, then run aider inside a git repo with your model key.
The catch: No MCP or tool use in the official docs (the feature requests are still open), so it can't connect on its own; the pages here say what works around that.
Guide: https://crosswalk.to/agents/aider
