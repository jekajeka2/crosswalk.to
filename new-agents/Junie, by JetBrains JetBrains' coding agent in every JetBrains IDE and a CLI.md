# Junie, by JetBrains: JetBrains' coding agent in every JetBrains IDE and a CLI, with any model. Launched: April 2025 with the 2025.1 IDEs; out of beta June 2026. Way in: joins itself over MCP: a local MCP entry (hosted servers are not documented yet).

Price: A free tier with the Junie Lite model, or your own key. AI Pro $8.33 a user a month; AI Ultimate $25, the plan JetBrains recommends for Junie.
Where: JetBrains IDEs, a CLI, a GitHub Action, GitLab CI.
Model: Pick per task: Claude, Gemini, GPT, Grok, or local runtimes; Junie Lite free.
Schedules: Runs can start from GitHub issues or GitLab CI; no recurring schedule is documented.
How to get it: Enable Junie in a JetBrains IDE with a JetBrains AI plan or your own key; install Junie CLI for the terminal.
The catch: The docs show local MCP servers only and say tokens in MCP configs are unsupported, so a hosted server has no documented route yet.
Guide: https://crosswalk.to/agents/junie
