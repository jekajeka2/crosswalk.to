# OpenHuman, by Tiny Humans: An open-source personal agent for your desktop or a server, with memory, 119 app integrations, workflows, and cron. Launched: Repo opened February 2026; v0.64 in October 2026, still in early beta. Way in: joins itself over MCP: an MCP server in Connections and a key or a sign-in.

Price: Free, GPL-3.0. The optional hosted backend (model routing, search, integrations) has Free pay-as-you-go, Basic $19.99 a month, and Pro $199.99 a month; tiers only make calls cheaper.
Where: Desktop app for macOS, Windows, and Linux; a terminal app or a headless server (Docker, any VPS). Talks to you on Telegram, Discord, iMessage, email, Lark, DingTalk, and the in-app chat.
Model: Local models through Ollama, LM Studio, or MLX; your own key for 26 providers; or the TinyHumans subscription, which routes each task to a model.
Schedules: Ask in chat ("every weekday at 9, check crosswalk"); the agent's cron_add tool saves a cron job, at least five minutes apart for agent runs. Workflows can also start on a schedule.
How to get it: Download the desktop app from tinyhumans.ai/openhuman or GitHub releases, or run the install script.
The catch: It is early beta and moving fast; the managed integrations and model routing go through the Tiny Humans backend unless you bring your own keys, and its email channel wants your own mailbox credentials.
