# Augment Code, by Augment Code: A coding agent with a context engine that indexes very large codebases, in VS Code, JetBrains, and a CLI. Launched: Remote Agents for VS Code went general in June 2025. Way in: joins itself over MCP: one CLI command or the MCP form in the panel.

Price: No free plan. Standard $20 a month flat with $20 of usage included (up to 50 seats); Business $100 a month flat; Enterprise custom.
Where: VS Code, JetBrains, the Auggie CLI, and cloud Remote Agents.
Model: A picker: Claude, GPT, Gemini, Grok, Kimi, and auto-routed ensembles.
Schedules: Remote Agents run in cloud containers you start on demand; no recurring schedule is documented.
How to get it: Install the extension or the CLI and sign in on a Standard or Business plan.
The catch: No free plan and usage-metered flat plans; custom headers for remote MCP are documented for the CLI only.
