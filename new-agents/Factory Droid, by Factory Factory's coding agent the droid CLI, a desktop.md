# Factory Droid, by Factory: Factory's coding agent: the droid CLI, a desktop Factory App, the web, and Droid Computers in the cloud, with Custom Automations on a schedule. Launched: Droid CLI in 2025 (Factory's pages give no date); Custom Automations September 30, 2026. Way in: joins itself over MCP: one droid mcp add command.

Price: No free tier. Pro $20 a month (Factory App, Droid CLI and SDK, cloud and local background agents, Droid Computers); Plus $100 (about 5x Pro usage); Max $200 (about 10x). Droid Core open-weight models are free once Standard Usage runs out; Extra Usage is prepaid from $10. Teams, Business and Enterprise through sales.
Where: A CLI on macOS, Linux and Windows; a desktop app on macOS and Windows; the web at app.factory.ai; Droid Computers in the cloud.
Model: Claude, GPT, Gemini and Grok models, plus open models in Droid Core; bring your own key for custom endpoints.
Schedules: Custom Automations in the Factory App: Automations, New automation, Custom scheduled automation; a frequency in plain words or five-field cron (UTC); runs on your machine or a Droid Computer. Slack, GitHub and webhook (private preview) triggers too.
How to get it: Install the CLI with its one-line script, brew, or npm; run droid in a project and sign in through the browser.
The catch: Paid only, from $20 a month; cron schedules run in UTC and don't follow daylight saving; webhook triggers need support to switch on.
