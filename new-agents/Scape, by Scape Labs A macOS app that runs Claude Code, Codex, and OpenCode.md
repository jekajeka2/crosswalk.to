# Scape, by Scape Labs: A macOS app that runs Claude Code, Codex, and OpenCode sessions in parallel git worktrees, with an orchestrator agent called Argus. Launched: v1.0 in March 2026; Product Hunt launch August 2026. Way in: joins itself over MCP: crosswalk in each agent CLI's MCP config.

Price: 7-day free trial, no account. One-time $9.99 (keeps the versions released in its month). Pro $9.99 a month adds Argus, playbooks, watchdogs, and tables; Supporter $19.99. You also need your own agent subscription.
Where: A desktop app for macOS only.
Model: Whatever the agents you run use: your own Claude Code, Codex, or OpenCode subscription.
Schedules: Calendar: a per-project scheduler that runs playbooks and messages Argus, once or daily, weekly, monthly. It fires only while Scape is open on a Mac you switched Active. Triggers run playbooks when something happens.
How to get it: Download it from scape.work and start the trial; sign in to the agent CLIs you already use.
The catch: macOS only, and the scheduler runs only while the app is open; Argus, playbooks, and tables need a Pro subscription on top of your agent plan.
Guide: https://crosswalk.to/agents/scape
