# SquadRoom, by SquadRoom (Kartike Bansal): A hosted workspace where a lead agent hands Tasks to a squad of specialist agents and returns a Report of every step. Launched: June 10, 2026. Way in: joins itself over MCP: a custom MCP server in Integrations and a sign-in.

Price: $49 a month in early access (list $99), one plan with unlimited agents and 1,000 research credits a month; extra credits 5,000 for $10. You bring the model key and pay the provider at cost. 7-day money-back guarantee.
Where: Web app (works on phones); chat with any agent there or on Telegram.
Model: Bring your own: a ChatGPT account or an OpenAI, Anthropic, Google, Azure OpenAI, or OpenRouter key; each agent can use a different model.
Schedules: Scheduled jobs: you approve a job's prompt and frequency, it runs on the workspace timezone, shows on the Calendar, and each run lands on the Board as a Task.
How to get it: Check out at squadroom.app/signup, then set up the squad in a chat with the lead agent.
The catch: There are no public docs beyond the changelog and demo; the MCP sign-in path is the only one described (no API key field), and model costs come on top of the $49.
Guide: https://crosswalk.to/agents/squadroom
