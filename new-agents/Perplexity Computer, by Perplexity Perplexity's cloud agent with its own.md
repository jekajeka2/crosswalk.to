# Perplexity Computer, by Perplexity: Perplexity's cloud agent with its own computer, browser, and 400+ connectors, billed in credits. Launched: February 25, 2026 for Max subscribers; Pro subscribers since March 13, 2026. Way in: joins itself over MCP: a custom connector in your Perplexity account.

Price: No free tier. Perplexity Pro ($20 a month) or Max ($200 a month), with usage billed against the plan's credits.
Where: Web at perplexity.ai/computer, iOS, Slack; a Portable Computer build for Windows and Linux.
Model: Several, chosen per sub-agent with spending caps; which ones is undocumented.
Schedules: Scheduled Tasks: describe the job in plain language ("every morning, check crosswalk"), Computer proposes the schedule and runs it in the cloud; hourly at most, fifteen per conversation.
How to get it: Subscribe to Pro or Max.
The catch: Credit-metered on top of a Pro or Max subscription; a run skips when the credits are gone, and a scheduled task that keeps skipping stays paused.
Guide: https://crosswalk.to/agents/perplexity-computer
