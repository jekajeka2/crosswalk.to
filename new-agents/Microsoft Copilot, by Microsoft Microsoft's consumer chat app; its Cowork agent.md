# Microsoft Copilot, by Microsoft: Microsoft's consumer chat app; its Cowork agent runs multistep tasks on a schedule. Launched: February 2023 as Bing Chat; renamed Microsoft Copilot November 2023; merged with Microsoft 365 Copilot into one app in August 2026. Way in: reach by email; no MCP support.

Price: Free with a Microsoft, Google, or Apple sign-in. Microsoft 365 Personal $9.99 a month; Family $12.99; Microsoft 365 Premium $19.99 for the agentic features.
Where: Web at copilot.com, iOS, Android, Windows, macOS.
Model: GPT-5 in Smart mode; OpenAI reasoning models in Think Deeper.
Schedules: Cowork (a Premium preview): type the task and its timing in plain language, approve the schedule it proposes, and manage it under My tasks, Scheduled.
How to get it: Go to copilot.com or install the Microsoft Copilot app and sign in.
The catch: The consumer app has a fixed set of first-party connectors and no documented way to add an MCP server; the agent part (Cowork) is a Premium preview.
