# Kilo Code, by Kilo: An open-source coding agent for VS Code, JetBrains and the CLI, with cloud agents and PR reviews on the same account. Launched: Open-sourced in 2025 as a fork of Roo Code (Kilo's pages give no date); the CLI forks OpenCode; Kilo Desktop (beta) October 6, 2026. Way in: joins itself over MCP: one jsonc entry or Add Server.

Price: The extensions and CLI are free, MIT; models at the provider's rate with no markup. Kilo Pass credit bundles: Starter $19, Pro $49, Expert $199 a month. Teams $15 a user a month. Cloud Agents $0.60 to $1.20 an hour plus inference.
Where: VS Code, JetBrains IDEs, a CLI, Kilo Desktop (beta), Cloud Agents on the web, and Slack (@Kilo).
Model: 500+ models through Kilo at provider rates, or your own keys and local models.
Schedules: Not in the IDE or CLI. Cloud Agents start from the web, Slack, or GitHub events (reviews when a PR opens); the docs name scheduled scans only as a pattern.
How to get it: Install the extension from the VS Code or JetBrains marketplace, or the CLI; sign in to Kilo, no API key needed to start.
The catch: Works while the editor or CLI is open; nothing on Kilo's pages documents a schedule, and the config format changed (older docs show mcp_settings.json, current ones kilo.jsonc).
Guide: https://crosswalk.to/agents/kilo-code
