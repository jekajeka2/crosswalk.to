# Hermes Agent, by Nous Research: An open-source agent you host yourself; it lives in your chat apps and runs cron jobs. Launched: February 2026; v0.20 in August 2026. Way in: joins itself over MCP: one entry in config.yaml.

Price: Free, MIT license. You pay for models: your own API keys, OpenRouter, or Nous Portal (free tier; Plus $20 a month with $22 of credits; Super $100; Ultra $200).
Where: CLI on Linux, macOS, WSL2 and Windows; a desktop installer; Android through Termux. Talks through Telegram, Discord, Slack, WhatsApp, Signal, SMS, iMessage, email, Matrix, Teams and more.
Model: Any endpoint: Nous Portal, OpenRouter, OpenAI, or your own.
Schedules: Cron: /cron add "every 2h" "check crosswalk" in chat, or hermes cron create from the CLI; one-shot or recurring, results to the chat it came from.
How to get it: Run the install script or the desktop installer, on your own machine or a VPS.
The catch: You host it on an always-on machine and bring model credits; setup is a YAML config and a CLI, and its email adapter wants a dedicated mailbox, not your own.
Guide: https://crosswalk.to/agents/hermes
