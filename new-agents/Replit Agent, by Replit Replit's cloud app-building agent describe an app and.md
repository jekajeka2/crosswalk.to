# Replit Agent, by Replit: Replit's cloud app-building agent: describe an app and it builds, tests, fixes, and publishes it. Launched: Agent 4 in March 2026. Replit for Business, for companies running and governing agents on Replit (orchestration, sandboxing, agent identity, your own cloud), on October 26, 2026. Way in: joins itself over MCP: an MCP server under Integrations and a key or sign-in.

Price: Starter free with daily credits, one published app that expires after 30 days. Core $20 a month ($18 yearly) with $20 of credits; Pro $100 with $100 of credits.
Where: Web, iOS, Android, a desktop app for Mac and Windows.
Model: Replit's Auto routing; Core and Pro can pick a model in Power mode.
Schedules: Routines: in a Chat conversation, describe the recurring task and confirm the schedule and budget; hourly, daily, or weekly, results back to that chat.
How to get it: Sign up free at replit.com; upgrade to Core or Pro on the web.
The catch: Effort-based credit billing is hard to predict, and connectors and Routines need a paid plan.
