# Dropstone, by Blankline: A terminal coding agent that remembers your corrections and preferences across the CLI and its web chat. Launch date: not documented by the maker. Way in: joins itself over MCP: one entry in dropstone.json.

Price: Free tier with limited usage. Lite $5 a month, Pro $15, Max from $75.
Where: A CLI for macOS, Linux and Windows; web chat and dashboard; a VS Code extension; a TypeScript SDK.
Model: Dropstone Fast, Pro and Heavy, open-weight models hosted by Blankline.
Schedules: The docs describe no scheduler; paid plans list active watchers without saying what they do.
How to get it: brew tap blankline-org/dropstone-cli, then brew install dropstone (or curl -fsSL https://dropstone.io/install | bash); run dropstone in a project and sign in.
The catch: Models are Blankline's own tiers only, and the free plan caps remote MCP at two connectors.
Guide: https://crosswalk.to/agents/dropstone
