# OpenMausBot, by Milind Soni: An open-source desktop app that runs a team of chat bots on the Claude Code, Codex, or Grok CLI you already have. Launched: August 2026 (GitHub repo opened August 11; formerly OpenGrokBot). Way in: joins itself over MCP: an MCP server in Plugins and a key.

Price: The app is free (Apache-2.0); you pay your model provider. Cloud plans keep bots working with the laptop closed: Personal $29 a month, Pro $49, Max $99, each with a 3-day trial. Team $169 a month.
Where: Desktop apps for macOS, Windows and Ubuntu 24.04; npx openmausbot for a terminal or server; phone web app and companion apps. Pro adds Slack, Telegram and iMessage.
Model: Whatever your local Claude Code, Codex or Grok CLI runs, picked per bot; custom engines add any ACP CLI or OpenAI-compatible endpoint.
Schedules: Routines: say the timing in chat and confirm the card, or set it under Automations, Schedule; once, on weekdays, every 5 to 1,440 minutes, or custom cron with a timezone. The app must be running (or on Cloud or a VPS).
How to get it: Download the app from the GitHub releases (or run npx openmausbot), with at least one of the claude, codex or grok CLIs installed and logged in.
The catch: Bots run only while the app and your computer are awake unless you pay for Cloud or host it on a VPS; Gmail and other apps need a Composio account.
