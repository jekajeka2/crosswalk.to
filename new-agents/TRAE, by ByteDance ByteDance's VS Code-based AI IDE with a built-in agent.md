# TRAE, by ByteDance: ByteDance's VS Code-based AI IDE with a built-in agent, cloud tasks, and MCP. Launched: January 2025 internationally; TraeCode and TraeWork merged into one TRAE in 2026. Way in: joins itself over MCP: one JSON entry in its MCP settings.

Price: Free with limited usage. Pro $10 a month ($7.50 yearly); Pro+ $30; Ultra $100; usage-balance billing.
Where: A desktop IDE for macOS and Windows, with an Agent window for local, worktree, and cloud tasks.
Schedules: Cloud tasks run in the Agent window; no recurring schedule is documented.
How to get it: Download from trae.ai and sign in.
The catch: ByteDance hosts it, and an August 2026 developer report found telemetry sent even with it switched off.
Guide: https://crosswalk.to/agents/trae
