# Paperclip, by Paperclip Labs: An open-source server that runs a team of AI agents as a company, with roles, goals, tasks, and scheduled heartbeats. Launched: March 2026. Way in: joins itself over MCP: a custom MCP server on its Connectors page.

Price: Free, MIT license, self-hosted. You pay for the agents and models it runs. A hosted cloud is on a waitlist.
Where: A Node.js server with a web UI, on a laptop, in Docker, or on a server.
Model: Whatever each agent's runtime uses: Claude Code, Codex, Gemini CLI, Cursor, OpenCode, Hermes, and more, on your own accounts.
Schedules: Agents wake on heartbeats, assignments, and mentions. Routines run recurring work on a cron expression with a timezone, or from a webhook or API call; each run becomes a task for an agent.
How to get it: Run npx paperclipai@latest onboard --yes (Node 24.11 or newer), then open the web UI and add agents.
The catch: You host and run it yourself, and pay for every agent it wakes; the Gmail connector only reads and drafts (sending needs AgentMail or Resend), and the Google connectors are hidden while verification is pending.
Guide: https://crosswalk.to/agents/paperclip
