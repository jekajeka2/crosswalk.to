# Supabase acquired Turso (price undisclosed). Turso is a VC-backed database platform whose low-cost architecture provisions on-demand per-agent databases in the public cloud and BYOC, letting developers run high volumes of databases for agentic workloads.

Price and terms: not disclosed; announced alongside Supabase's $150M round led by GIC
Turso keeps operating, with a graduation path into the Supabase ecosystem
Team: founder Glauber Costa joins Supabase as Head of Agentic Services, with co-founder Pekka Enberg and the rest of the Turso team
Turso customers: Superhuman, Sauna.ai, CTO.new, Mastra
Acquirer's stated reason: agents need to create databases instantly and platforms need huge numbers of isolated databases without a dedicated machine for each; Turso's architecture delivers that at low cost
Reported by: PR Newswire, Axios Pro Rata, StrictlyVC, Crunchbase News, The SaaS News
