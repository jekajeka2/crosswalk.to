# Ghost raised $11M seed led by Andreessen Horowitz. Ghost makes Core, a $3,499 screenless personal computer with a bundled Nvidia RTX Pro 4000 SFF Blackwell GPU, built to run AI agents locally on a user's own data and act on their behalf.

Other investors: Abstract, Audacious Ventures, SV Angel, Nova
HQ: San Francisco, CA (units built at its San Francisco facility)
Founders: Zain Javaid (CEO, 19), Nicholas Chua, Yifei Chen, Gautam Sharda; emerged from stealth after a year of building
Product: Core ships with Qwen-3.8-Next, Qwen-3.8-27B and Gemma-4-31B preinstalled; models and personal memory run on-device, encrypted; over-the-air model updates; an outbound-request firewall flags agent actions for user review
Traction: preorders open 2026-10-05; first batch ships the last week of October
Reported by: TechCrunch
