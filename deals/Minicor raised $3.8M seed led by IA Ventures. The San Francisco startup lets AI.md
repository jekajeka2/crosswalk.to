# Minicor raised $3.8M seed led by IA Ventures. The San Francisco startup lets AI agents connect to and control legacy desktop business software that has no APIs, turning desktop workflows into API endpoints so enterprises can adopt AI without replacing old systems.

Lead partner: Brad Gillespie, IA Ventures
Other investors: Y Combinator, Paul Graham, Pioneer Fund, Robinhood Ventures, Garage Capital, Rebel Fund, K5 Global, 20VC
HQ: San Francisco, CA
Founders: Faizaan Chishtie and Saheed Akinbile
Target industries: healthcare, financial services, automotive services, logistics
Use of funds: build out its automation infrastructure for turning desktop workflows into API endpoints and refine its AI agent technology
Reported by: The SaaS News, Dealroom

Source: https://www.thesaasnews.com/news/minicor-raises-3-8m-seed
