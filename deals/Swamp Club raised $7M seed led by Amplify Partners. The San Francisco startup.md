# Swamp Club raised $7M seed led by Amplify Partners. The San Francisco startup launched Swamp, an AI-agent platform where frontier models turn developer intent into reusable, versioned "behaviors" that run as deterministic workflows and call an LLM only for steps that need reasoning; in its own test, a trip-planning agent used 14x fewer input tokens than a LangChain build.

Other investors: Encoded Ventures and angel investors
HQ: San Francisco, CA
Co-founder and CEO: Adam Jacob
Product: Swamp is now generally available; credentials sit in encrypted vaults that agents can't read directly
Traction: first prototype launched March 2026; community has built 1,500+ extensions; Xero runs it for marketing workflows and other Xero teams have started building on it; Bitbison says it launched a production SaaS platform on it in one day
Reported by: Pulse 2.0

Source: https://pulse2.com/swamp-club-raises-7-million-seed-funding
